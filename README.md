# نور — مصحف الختمة

مصحف داخل المتصفح يساعدك على ختم القرآن آية آية، مع حفظ تقدمك محليا دون حساب.

## المزايا

- فهرس 114 سورة مع بحث بالاسم العربي أو الإنجليزي أو الرقم.
- قراءة بالرسم العثماني بخط أميري، مع تكبير وتصغير الخط.
- تعليم الآية كمقروءة باللمس، واللمس الثاني يتراجع.
- لوحة ختمة: نسبة مئوية، شريط تقدم، ورد اليوم مع هدف قابل للتعديل، آخر قراءة، عدد الختمات.
- زر «تابع» يرجعك لآخر آية، وزر «إتمام السورة» يعلم كل آيات السورة الحالية.
- تنقل بلوحة المفاتيح (أسهم، Enter، مسافة) ودعم قارئ الشاشة.
- 4 سور تعمل دون إنترنت (الفاتحة، الإخلاص، الفلق، الناس)، والباقي يُحفظ بعد أول تحميل.

## التشغيل محليا

لا يحتاج بناء. افتح المجلد كخادم ثابت ثم افتح الصفحة:

```bash
cd quran-app
python3 -m http.server 8000
# افتح http://localhost:8000
```

ملاحظة: فتح `index.html` مباشرة ببروتوكول `file://` قد يمنع جلب `data/surahs.json` في بعض المتصفحات، لذلك يفضل خادم محلي.

## هيكل المشروع

```
quran-app/
  index.html          الهيكل: هيدر + بحث + لوحة 3 بطاقات + فهرس + قارئ
  css/style.css       الثيم الأخضر والشبكة المتجاوبة
  js/app.js           المنطق: الحالة، الفهرس، التحميل، التعليم، الإحصاء
  js/offline-surahs.js نص 4 سور مضمن للعمل دون نت
  data/surahs.json    فهرس 114 سورة (رقم، اسم، إنجليزي، عدد آيات، نوع)
  assets/logo/        الشعار بثلاثة مفاهيم + favicon + دليل USAGE.md
```

## كيف يعمل باختصار

- الحالة في `localStorage` بمفتاح `quran_tracker_v1`: قائمة مفاتيح `سورة:آية` للمقروء، وآخر قراءة، وسجل يومي، وهدف، وحجم خط.
- نص السور في `localStorage` ببادئة `surah_cache_` بعد أول جلب من `api.alquran.cloud`.
- النسبة = عدد المقروء ÷ 6236.

## الشعار

انظر `assets/logo/USAGE.md`. المفهوم المعتمد حاليا C1 «نون الختمة» (`noor-c1-icon-color.svg` في الهيدر و`favicon.svg` للتبويب).

## الخصوصية

كل البيانات في متصفحك وحده. لا حسابات ولا إرسال لطرف ثالث باستثناء جلب نص السور من API عند أول مرة.
